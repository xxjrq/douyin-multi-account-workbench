# Douyin Multi-Account Workbench

Run public, read-only Douyin research for explicitly selected EasyBR browser environments and aggregate the results by account. Each account keeps its own browser ID, session group, evidence links, status, and script draft.

Install and verify the four declared atomic skills before running: `douyin-live-hot-free`, `douyin-account-diagnosis`, `douyin-comment-insights-free`, and `douyin-competitor-research-free`. The workbench never stores credentials or performs comments, messages, submissions, or publishing.
